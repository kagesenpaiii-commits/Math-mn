Ахлах Анги Математик Томьёоны Лавлах

1. Тригонометрийн Адилтгалууд

• \(\sin^2(x) + \cos^2(x) = 1\)
• \(\tan(x) = \frac{\sin(x)}{\cos(x)}\)
• \(\sin(2x) = 2\sin(x)\cos(x)\)
• \(\cos(2x) = \cos^2(x) - \sin^2(x)\)

2. Логарифм ба Илтгэгч Чанарууд

• \(\log_a(xy) = \log_a(x) + \log_a(y)\)
• \(\log_a(\frac{x}{y}) = \log_a(x) - \log_a(y)\)
• \(\log_a(x^k) = k \cdot \log_a(x)\)
• \(\log_a(b) = \frac{\ln(b)}{\ln(a)}\)

3. Уламжлал ба Интеграл

• \((x^n)' = n \cdot x^{n-1}\) | \(\int x^n dx = \frac{x^{n+1}}{n+1} + C\)
• \((\sin x)' = \cos x\) | \(\int \cos x dx = \sin x + C\)
• \((\cos x)' = -\sin x\) | \(\int \sin x dx = -\cos x + C\)
• \((e^x)' = e^x\) | \(\int e^x dx = e^x + C\)
